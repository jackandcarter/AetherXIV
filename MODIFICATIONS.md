# AetherXIV Development and Modification Notice

AetherXIV is an independently maintained Final Fantasy XIV 1.23b preservation
platform.

Development of AetherXIV 2.0 began in 2026. Its contributors have developed
new server architecture, launcher and patch-distribution systems, protocol
implementations, persistence systems, cross-platform support, diagnostics,
deployment tooling, and replacement gameplay behavior.

Some repository components incorporate implementation and content from Project
Meteor Server. AetherXIV is progressively replacing historically inherited
implementation with independently written and documented AetherXIV
components.

Major AetherXIV work includes:

- Reworked server and service architecture
- New launcher and patch-distribution systems
- Umbra plugin framework integration
- Database migrations and persistence improvements
- Corrected lobby, world, map, actor, director, and tutorial behavior
- Protocol implementations verified against original network captures
- Modern Windows, macOS, Linux, Wine, and hosting support
- New diagnostics, tracing, configuration, deployment, and build systems
- Replacement of incomplete or placeholder gameplay behavior
- Continued replacement of historically inherited implementation

The repository history records when files were introduced, replaced, or
substantially modified.

AetherXIV is not an official Project Meteor release and is not maintained,
endorsed, or supported by the Project Meteor team.
