# Contributing to AetherXIV

AetherXIV welcomes contributions that improve preservation accuracy,
compatibility, reliability, documentation, and maintainability.

## License

By submitting a contribution, you represent that you have the right to submit
it and agree that it is licensed under the GNU Affero General Public License,
version 3 or later.

Contributors retain copyright in their contributions.

Do not submit code, assets, captures, credentials, or other material that you
do not have the right to distribute. Do not copy implementation from
incompatibly licensed or proprietary projects.

## Developer Certificate of Origin

Every commit must include a `Signed-off-by` line certifying the Developer
Certificate of Origin in `DCO`.

Use:

```sh
git commit -s
```

The sign-off certifies origin and permission to contribute; it is not a
copyright assignment.

## Source notices

New, nontrivial AetherXIV source files should carry the repository's standard
copyright and AGPL notice. Preserve applicable notices already present in
files you modify.

Generated files, third-party files, and binary assets should retain their
native notices and should not receive an AetherXIV authorship claim.
